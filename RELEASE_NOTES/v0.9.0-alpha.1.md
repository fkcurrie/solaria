# Solaria v0.9.0-alpha.1 Release Notes

Release Date: August 28, 2026  
Release Tag: v0.9.0-alpha.1  
Release Type: Pre-Release (Alpha 1 Candidate)  

---

## Overview and Strategic Focus

Solaria v0.9.0-alpha.1 represents a major evolutionary step in autonomous solar telemetry, off-grid hardware resilience, and automated code governance. This release eliminates legacy hardcoded site coordinates, introduces a three-tiered location resolution architecture, establishes an industry-standard static analysis linter suite, and integrates automated pull request code quality and security review bots.

---

## Urgent Upgrade Notes and Action Required

### Configuration Migration: Removal of Static Location Defaults
Legacy releases defaulted site coordinates to hardcoded fixed values (45.186 N, -78.863 W) and solar array capacity to 400W across system daemons and installer scripts.

Starting in v0.9.0-alpha.1:
- System daemons dynamically resolve site coordinates through a fallback hierarchy: local hardware GPS receiver (gpsd) -> network IP geolocation -> environment variable overrides -> safe baseline fallback.
- If explicit fixed location coordinates are required, administrators must set SITE_LATITUDE and SITE_LONGITUDE in /etc/solaria/solaria.env or system environment variables.

---

## Major Features and Enhancements

### Multi-Tiered Site Location Resolver
- Implemented pkg/location/resolver.go providing automatic, fault-tolerant site coordinate detection.
- Tier 1: Reads SITE_LATITUDE, SITE_LONGITUDE, and SITE_NAME from environment variables.
- Tier 2: Queries local gpsd TCP socket daemon (127.0.0.1:2947) for TPV mode fixes.
- Tier 3: Performs HTTP IP geolocation requests using primary (ip-api.com) and secondary (ipinfo.io) endpoints with strict timeout constraints.
- Tier 4: Falls back to safe baseline default if offline and unconfigured.

### Multi-Linter Suite and Code Quality Governance
- Added .golangci.yml configuring 10 active Go linters: errcheck, gofmt, gosec, govet, ineffassign, staticcheck, unused, misspell, bodyclose, and copyloopvar.
- Added automated GitHub Actions workflow .github/workflows/golangci-lint.yml running on all pushes and pull requests.

### Automated PR Security Bot Reviewer and Slash Commands
- Integrated .github/workflows/pr-bot-reviewer.yml to execute govulncheck, gosec, gofmt, and unit tests on incoming pull requests, posting automated review scorecards and labeling PRs with quality-pass and security-pass.
- Added .github/workflows/slash-command-reviewer.yml enabling on-demand bot reviews via /review or /audit comments on pull requests.

### Automated Dependency Management
- Added .github/dependabot.yml configuring weekly automated vulnerability scanning and version updates for Go modules and GitHub Actions workflows.

### Automated 31-Probe E2E Audit in CI
- Integrated bin/solaria-e2e-audit into .github/workflows/bootstrap-ci.yml to validate end-to-end subsystem communication across 31 system probes on every commit.
